# Portal de Estudos - Escrevente TJSP 📚
Bem-vindo ao Portal de Estudos para o concurso de Escrevente do TJSP! Este é um projeto simples e direto, criado para centralizar e facilitar o acesso a materiais de estudo essenciais.
A página principal funciona como um "link na bio", reunindo todos os links importantes para os seus materiais de estudo hospedados no GitHub Pages.
✨ Sobre o Projeto
Este projeto nasceu da necessidade de organizar os materiais de estudo de forma prática e acessível. O objetivo é oferecer um ponto de acesso único e gratuito para todos os concurseiros que estão se preparando para o TJSP, com recursos como:
 * Flashcards/Fichas de Estudo: Para memorização e revisão rápida.
 * Quizzes Interativos: Para testar seus conhecimentos e fixar o conteúdo.
 * Legislação Compilada: Acesso direto às leis mais importantes do edital.
Todo o conteúdo é 100% gratuito e feito para ajudar a comunidade de estudantes.
🚀 Tecnologias Utilizadas
Este projeto foi construído com tecnologias web modernas e de fácil manutenção:
 * HTML5 para a estrutura do conteúdo.
 * Tailwind CSS para uma estilização rápida e responsiva.
 * JavaScript para as funcionalidades interativas dos quizzes e flashcards.
